# 🐾 Quadruped Robots – Literature & GitHub Resources

This repository is a curated collection of research papers, summaries, and open-source GitHub repositories related to quadruped robot locomotion. It is intended to serve as a resource hub for researchers, engineers, and students working on legged robotics, reinforcement learning, and control systems.

## 📄 Contents

### 🔬 Papers/
Summaries of important research papers in quadruped robotics. Each summary includes:
- 🧠 Key Ideas & Contributions
- ⚙️ Algorithms and Architectures
- 📈 Experiments and Results
- 🔍 Notable Insights

Use the included `Paper Summary Template.md` to add new papers consistently.

### 📚 Quadruped Robots Literature Survey
A structured literature review discussing the evolution of quadruped locomotion research. Covers:
- Policy learning methods
- Recovery controllers
- Sim-to-real transfer
- Multi-robot generalization
- Future challenges

### 💻 Quadruped Robots – GitHub Resources
A curated list of open-source GitHub repositories for:
- Simulation environments (e.g. MuJoCo, IsaacGym, PyBullet)
- Reinforcement learning pipelines
- Controllers for standing, walking, trotting, and recovery
- Real-world robot platforms (e.g. Unitree, ANYmal, Solo)
